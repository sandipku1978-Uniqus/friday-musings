Give my concierge a chore

Muse launched US-only and dots needs a paid ChatGPT plan, so most of India can't try a personal agent yet. This one runs for anyone. It books with demo businesses that answer agents, builds your calendar, and drafts the messages you still need to send, inside a mandate you set.

What happens when you press Run
  1. The concierge sorts your message into errands.
  2. For errands with a gateway (restaurant, clinic, home repairs, insurance, gym) it calls the business's agent and gets a real offer.
  3. It commits within your mandate, and stops to ask you when it must.
  4. Everything else becomes a calendar entry or a ready-to-send message.

Point your own agent at our businesses

The demo businesses publish real agent cards and answer real requests. Any agent can call them, including yours.

curl /.well-known/agent-card.json

curl -X POST /gateway/saffron-room \
  -H 'Content-Type: application/json' \
  -d '{"intent":"availability.search","city":"mumbai",
       "params":{"date":"","time":"20:00","party_size":4}}'

Receipts are signed with Ed25519. The public key is in every agent card.
