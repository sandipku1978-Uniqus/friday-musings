# Solve a Rubik's Cube: 7 steps, age 8 and up

An animated, kid-friendly tutorial video for the #FridayMusings series by Sandip Khetan.
One method (beginner, layer by layer), seven steps in order, a robot hand doing every move,
and an original soundtrack.

- Watch: `output/rubiks_cube_7_steps.mp4` (with sound) or `output/rubiks_cube_7_steps.gif`
- Rebuild: `pip install -r requirements.txt`, install ffmpeg, then `python build.py`
- Quick check of one step: `python build.py --only 4`
- Post text: `content/linkedin_post.md`

Working on this with Claude Code? Start with `CLAUDE.md`: it has the architecture, the rules the
video follows, verified facts and the open items.
